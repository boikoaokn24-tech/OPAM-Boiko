*Чому рядки exit з'являються у зворотному порядку до enter?*
Рядки exit з'являються у зворотному порядку через природу стека викликів (LIFO — Last In, First Out). Функції, які викликаються останніми (глибші рекурсивні рівняння), завершуються та звільняються зі стека першими, після чого керування повертається до батьківських функцій.

### Відповіді на питання із завдання 5:
1. *Який запис зрозуміліший для цієї задачі — рекурсивний чи циклічний, і чому?*
Для задачі перевірки рівності всіх елементів циклічний запис набагато зрозуміліший, простіший у написанні та ефективніший за пам'яттю та часом виконання, оскільки лінійний перебір масиву не потребує накладних витрат на рекурсивні виклики та поділ індексів навпіл.

2. *Чому так само просто переписати циклом завдання 1 не вийде. Якої саме допоміжної структури даних для цього бракує?*
Переписати обхід файлової системи звичайним плоским циклом без рекурсії не вийде просто, оскільки глибина вкладеності каталогів заздалегідь невідома. Для ітеративної реалізації обходу дерева каталогів вручну бракує **стека** (або черги), у якому необхідно самостійно зберігати стан невиконаних батьківських директорій під час занурення вглиб файлової системи.
